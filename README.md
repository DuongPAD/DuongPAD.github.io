# duongpad.github.io

Support and privacy pages for my apps, one folder per app:

- `caro/` — Caro - Gomoku (iPhone, iPad, Mac): `caro/support/`, `caro/privacy/`
- `hopscape/` — Hopscape (Mac): `hopscape/support/`, `hopscape/privacy/`
- `itcompanystory/` — IT Company Story (Mac): `itcompanystory/` (about), `itcompanystory/support/`, `itcompanystory/privacy/`
- `metro-network/` — Metro Network (iPhone, iPad, Mac): `metro-network/` (about), `metro-network/support/`, `metro-network/privacy/`

A new app gets its own folder and a section in `index.html`.
